⚙ EmailJS Configuration

Configure EmailJS to enable automatic email sending for user registrations.

Setup Steps:

  1. Go to EmailJS.com and create a free account
  2. Create an Email Service (Gmail, Outlook, etc.)
  3. Create an Email Template with these variables: {{to_email}}, {{to_name}}, {{username}}, {{subject}}, {{message}} (do not include password fields)
  4. Get your Service ID, Template ID, and Public Key from EmailJS dashboard
  5. Enter them below and save
Found in EmailJS Dashboard -> Email Services
Found in EmailJS Dashboard -> Email Templates
Found in EmailJS Dashboard -> Account -> API Keys -> Public Key
